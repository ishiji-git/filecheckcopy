# タスク： ファイル同一性チェック付きファイルコピーツール

## 1. 背景と目的
- ファイルをバックアップするときにファイルの内容が異なる場合のみコピーする。
  巨大なファイルのコピー時間短縮、小ファイルでも書き込みによるディスク負荷の軽減が目的。
- コピー先はローカルのHDDの他、リモートマウントされたディスク（NAS等）も考慮する。

## 2. 仕様
- Windows 系OSが前提
- コピー元（ソース）からコピー先（ターゲット）に、コピーする。
- 例） コマンドライン起動：
    filecheckcopy.py source_dir target_dir
- コピー対象はファイル、あるいは、フォルダとする。
- フォルダを指定した場合には、フォルダをの再帰下降してファイルコピーする。
- 内容の異なるファイルのみコピーする。
- 内容のないフォルダ（カラのフォルダ）もコピーする（フォルダを作成する）。
- ファイルのタイムスタンプが異なっていても内容の差異を判定する。
- 内容の差異の判定はファイルのチェックサムあるいはハッシュ値を使う。
- ファイルのチェックサム/ハッシュ値算出アルゴリズムは自作・あるいはライブラリを使用する。
- チェックサム/ハッシュ演算は高速なアルゴリズムを使用する。ハッシュ衝突の考慮は重視しない。
  CRC32あるいはMD5SUM等だが別のアルゴリズムでも可。
- コピー元の属性（時刻、Attribute）が維持されること。
- オプション指定により、ファイルのタイムスタンプが同一の場合はコピーしないよう設定できること。
- オプション指定により、除外するフォルダ、ファイルを指定できる機能。（例：.git, .svnを除外等）

## 3. 実装条件
- Window系OS前提
- Python 3
- 標準ライブラリ意外を使用も可。ただしOSS等使用に関してフリーのもの。
